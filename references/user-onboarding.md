# What This Skill Can Do

Use this concise explanation only when the Skill is first invoked with no active workflow state, or when the user asks what the Skill can do, how the workflow works, or what the AI and human each do. Do not show it again when resuming an existing stage.

## What this Skill can handle

The Agent can research and validate source articles, shortlist strong source material, extract tensions and non-obvious ideas, generate three short-video angles and draft scripts, create storyboard references, generate stock-footage search keywords, suggest one background-music direction and search keywords, generate and score title options, and package the final AI-generated production materials.

## What still requires human review

Human review is required for choosing the final source article; checking source relevance and credibility; selecting the script angle; polishing and approving final wording; judging whether visuals fit the intended meaning; choosing the final music track; choosing the final title; and final quality control.

## What this Skill does not replace

The Skill does not replace editorial judgment, actual stock-footage selection, copyright/license verification, voice selection or final voice-over judgment, video editing, audio mixing, subtitle QC, final export, or publishing.

AI prepares strong options and structured production material; humans keep final editorial and creative control.

```text
Topic
→ Source Research
→ Human Source Selection
→ 3 Script Options
→ Human Selection + Polish
→ Storyboard
→ Music Direction
→ Title Options
→ Final Creator Handoff
→ Human Editing / QA / Publishing
```

If the user has already supplied a usable topic, do not ask for the topic again. After onboarding, preserve the topic already provided and proceed directly to Step 1 Source Research if enough information is available; otherwise ask only for a materially missing required input. If the user directly requests a later stage and supplies its required approved artefact, resume that stage without showing this onboarding or asking for a topic.
