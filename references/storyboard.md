# Storyboard

## Scope

Use only the final polished script. Preserve its sequence and meaning. Create 7–11 visual beats; merge or split beats when needed for a natural short-video rhythm. Do not prescribe editing actions or claim that a particular clip has been selected.

## Exact narration

For every visual beat, copy the exact corresponding narration segment from the approved polished script. Do not paraphrase, rewrite, shorten, expand, polish, or otherwise alter the narration. The storyboard is built around the approved script and must never modify it.

## Per-beat format

```markdown
### Beat 01 — [short purpose] | [approx. script span]
- Voice-over:
- Visual job:

- Chinese visual reference C:
- Stock search 1: [English] / [中文]

- Stock search 3: [English] / [中文]
- Stock search 4: [English] / [中文]
- Stock search 5: [English] / [中文]
- Stock search 6: [English] / [中文]
- Human note: choose footage that is licensable and actually supports the narration.
```

## Visual reference A / B / C roles

- **Visual Reference A — Direct / Most Searchable:** Provide the most direct, realistic, and easy-to-find stock-footage interpretation of the narration. For example, if narration discusses a manager closely supervising engineers, show a manager standing beside an engineer's desk and reviewing their screen.
- **Visual Reference B — Alternative Workplace Scenario:** Provide a different realistic workplace situation that communicates the same underlying idea. Do not simply rephrase Visual Reference A. For example, show a small technical team in a meeting where every decision appears to require the manager's approval.
- **Visual Reference C — Indirect / More Visual:** Provide a slightly more indirect or visually expressive interpretation using body language, workplace behavior, objects, close-up details, screens, team interaction, or physical contrast. It must remain realistic, professional, and searchable in ordinary stock libraries; do not make it surreal, excessively cinematic, unsearchable, or overly specific.

The three references must represent meaningfully different visual approaches. Bad: A: manager looking at engineer screen; B: supervisor looking at developer screen; C: boss checking programmer screen. Good: A: manager standing beside one engineer and reviewing the screen; B: technical team waiting for manager approval in a meeting; C: engineer pauses work and looks toward the manager before continuing.

## Visual guidance

Offer a mix of literal, contextual, human, environmental, and abstract references. Avoid generic “business meeting” repetition when the script needs a specific situation. Search terms should describe subject + action + context + visual style where useful. Mention the intended sources (Pexels, Videezy, Mixkit, Vidsplay), but do not search, download, license, or select the footage in this stage.

End with a short coverage check: every sentence has a visual job, no beat introduces unsupported meaning, and the human still must choose the actual clips.
